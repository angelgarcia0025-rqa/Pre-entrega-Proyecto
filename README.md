# Pre-entrega Automation Testing - Danni La Cruz

## Propósito del proyecto

Este proyecto automatiza pruebas básicas sobre el sitio SauceDemo usando Selenium WebDriver, Python y Pytest.

## Tecnologías utilizadas

- Python
- Selenium WebDriver
- Pytest
- Pytest HTML
- Git
- GitHub

## Funcionalidades automatizadas

- Login exitoso con credenciales válidas.
- Validación de la página de inventario.
- Verificación de productos visibles.
- Validación de elementos importantes como menú y filtro.
- Agregado de producto al carrito.
- Verificación del contador del carrito.
- Validación del producto dentro del carrito.
